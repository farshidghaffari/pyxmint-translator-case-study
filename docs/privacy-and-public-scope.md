# Privacy and public scope

## Scope

This repository contains documentation and conceptual diagrams presented as portfolio/reference material. Application implementation and private operational material are outside its scope.

## Included

Owner-approved product scope, role wording, qualitative field observations, clearly labeled proposed tests and functional diagrams. The approved location reference is Gyumri only; no specific venue or participant details are included.

## Excluded

- Private source code, source fragments, implementation repository links and commit history.
- API keys, access codes, secret names, routes and infrastructure identifiers.
- Internal deployment configuration, private analytics and operational exports.
- Real transcripts, recordings, participant details and customer/user information.
- Fake product UI, reconstructed screens presented as real screenshots, and invented field-test photography.

## Feature claims are not privacy guarantees

An optional transcript does not establish whether data is stored, deleted, retained or exported. An active-speaking time allowance does not establish billing, identity or enforcement details. The diagrams do not assert network isolation, security architecture or provider behavior.

## Visual policy

Follow the permanent Global Visual Realism Policy: prefer authentic safe screenshots or photographs, then useful technical diagrams. No approved safe screenshot is included in this package, so it uses diagrams only. Both SVGs are explicitly conceptual. The [system and disclosure boundaries diagram](../assets/diagrams/system-boundaries.svg) describes this documentation scope. There are no UI mockups or photographs. See [screenshot policy](../assets/screenshots/README.md).

## Review and release boundary

Review claims against the [evidence register](evidence-register.md). Any later new evidence needs independent privacy and claim checks. Publication of the case-study documentation does not include or authorize release of the private implementation. Any change to repository visibility requires a separate owner decision.
